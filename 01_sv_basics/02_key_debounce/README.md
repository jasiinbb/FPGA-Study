# Day 02 - 按键同步与消抖

## 1. 今日目标

完成一个真实 FPGA 输入信号处理工程：

```text
外部按键
   ↓
异步输入
   ↓
两级同步器
   ↓
消抖
   ↓
稳定按键事件
   ↓
LED状态翻转
```

今天重点理解：**为什么外部按键不能直接进入时序逻辑，以及同步和消抖分别解决什么问题。**

## 4. 推荐模块划分

建议不要把所有功能塞进一个 `always_ff`。

推荐逐步拆成：

```text
key_sync
    ↓
key_debounce
    ↓
key_edge_detect
    ↓
led_ctrl
```

也可以先完成单模块版本，再进行模块化重构。

## 5. 功能要求

实现一个按键控制 LED：

- 按键按下并稳定后产生一次有效事件。
- 按键松开并稳定后恢复空闲。
- 一次按键动作只能让 LED 翻转一次。
- 按键抖动不能造成 LED 多次翻转。
- 外部按键输入首先经过同步处理。
- 消抖时间必须参数化。
- RTL 必须可综合。

## 6. 参数建议

建议设计：

```text
ClkFreq
DebounceTimeMs
```

仿真时使用很小的参数，例如：

```text
ClkFreq = 10
DebounceTimeMs = 2
```

实际 FPGA 再根据开发板时钟修改。

## 7. Testbench 要求

TB 不应该只测试一次干净的按键电平。

至少模拟：

```text
空闲
 ↓
按下抖动
 ↓
稳定按下
 ↓
保持
 ↓
松开抖动
 ↓
稳定释放
```

重点观察：

- 原始 `key`
- 同步后的 `key_sync`
- 消抖后的 `key_clean`
- 按键事件 `key_pulse`
- `led`
- 消抖计数器
